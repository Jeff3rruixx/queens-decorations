# Queen's Decorations

Página web de Queen's Decorations: decoración de eventos sociales, productos de cuidado corporal y pijamas en Cali. Hacemos realidad tus deseos.

- `index.html`: la página pública con el catálogo y pedidos por WhatsApp.
- `admin.html`: panel para publicar, editar y eliminar productos y subir fotos.
- `productos.json`: el catálogo.
- `fotos/`: las fotos de los productos.
